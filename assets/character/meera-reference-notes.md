# MEERA — Visual Reference Notes

This file records non-explicit design details from the reference shared in the MEERA project conversation. It is not the original photograph.

## Character appearance
- Adult Indian woman character.
- Dark hair, neatly pulled back into a bun.
- Small bindi centered on the forehead.
- Delicate earrings.
- Natural-looking facial proportions and expressive eyes.
- Realistic human anatomy and proportions; avoid cartoon, mannequin, or exaggerated stylization.

## Project target
Create a photorealistic, full-body 3D character with realistic skin shading, detailed face, natural hair, anatomically plausible proportions, a properly deforming skeleton, and dance animation clips.

## Clothing target for the MEERA character
Use the project's established costume direction: white saree with bright pink and lime-green borders, lime-green blouse, and matching traditional jewellery.

The original reference photograph is intentionally not included in this public repository. Do not attempt to reconstruct or publish any explicit content from it. Use these non-explicit notes only as visual direction; request a clothed reference if an exact photographic likeness is needed.
